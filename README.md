## Features

- `/home` opens a menu with up to 5 beds
- Teleport, rename and delete your homes from the menu
- 5 second teleport countdown, cancelled if you move or get hit
- Home limit per rank with LuckPerms
- Works with Multiverse

## Install

1. Download `HomeGUI.jar`
2. Put it in your `plugins` folder
3. Restart the server

## Beds

- **White:** empty slot, click to set a home
- **Blue:** home set, click for Teleport, Rename and Delete
- **Gray:** no access to this slot

## Home limits

Everyone gets 1 home and OPs get 5. Give a rank more slots with LuckPerms:

| Permission | Homes |
| --- | --- |
| `homegui.homes.2` | 2 |
| `homegui.homes.3` | 3 |
| `homegui.homes.4` | 4 |
| `homegui.homes.5` | 5 |

```
/lp group vip permission set homegui.homes.3 true
```
